# AI 协作任务模板

## 任务名称：

填写本次任务的唯一名称，例如：Hermes 工程规则固化任务 002

## 主任务一句话：

用一句话描述本轮唯一目标。示例：在 video-api-debugger 项目中仅创建 AI 协作规则文档，不修改业务代码。

## 任务类型：

填写任务类型，例如：文档 / 工程流程固化、代码修复、只读审查、测试补齐、配置调整。

## 风险等级：

填写风险等级：低 / 中 / 高。

风险判断参考：

- 低：仅文档、注释或明确无运行时影响的改动。
- 中：普通 UI、非核心 API、局部类型或低风险逻辑调整。
- 高：鉴权、middleware、点数、权限、支付、上传、外链拉取、Provider 适配、Prisma、SQLite、`.env`、依赖和部署。

## 背景：

写明项目现状、已知结论、上游分析来源和本轮任务原因。

当前项目基线：

- 项目名称：video-api-debugger
- 技术栈：Next.js 14 + React 18 + TypeScript + Prisma + SQLite
- 高风险区域：鉴权 / middleware、点数 / credit 流程、上传与外链拉取、Provider 适配层、`.env` / 密钥管理、Prisma / SQLite 数据层

## 本轮只做：

逐条列出本轮必须完成的事项。每一条都应可验收，不写模糊目标。

示例：

- 创建或修改指定文档文件。
- 补充指定字段。
- 输出指定范围的 diff。

## 本轮不做：

逐条列出明确禁止事项，防止任务扩散。

video-api-debugger 常用禁止项：

- 不修改业务代码。
- 不修改点数、登录、权限、支付逻辑。
- 不修改 `package.json`、`package-lock.json`、`tsconfig.json`、`prisma/schema.prisma`、`.env`。
- 不安装依赖。
- 不提交、不 push、不发布。
- 不执行数据库修改。

## 允许修改文件/目录：

填写本轮允许 Codex 修改的精确文件或目录。

示例：

- `AGENTS.md`
- `CLAUDE.md`
- `docs/agent-task-template.md`
- `docs/agent-execution-log.md`

## 禁止修改文件/目录：

填写本轮禁止修改的文件或目录。

video-api-debugger 默认禁止高风险范围：

- `src/**`
- `prisma/**`
- `package.json`
- `package-lock.json`
- `tsconfig.json`
- `.env`
- `public/**`
- `storage/**`
- `.next/**`
- `.vercel/**`

## 执行步骤：

写明 Codex 应按什么顺序执行。

推荐顺序：

1. 只读确认仓库结构与相关脚本。
2. 对照允许修改范围创建或编辑文件。
3. 不触碰禁止范围。
4. 执行任务指定验证命令。
5. 汇报实际修改、验证结果、风险和 diff。

## 测试要求：

写明必须运行、禁止运行或可选运行的验证命令。

示例：

- 文档任务：不跑业务测试，只运行 `git diff -- <允许文件>`、确认实际修改范围、确认文件存在且非空。
- 代码任务：优先运行 `npm run lint` 和 `npm run build`；如需类型检查但项目无 `typecheck` 脚本，应如实说明。
- 数据库任务：除非明确授权，不运行迁移、`db:push`、种子脚本或会改变数据的命令。

## 验收标准：

逐条列出完成条件。

示例：

- 仅修改允许范围内的文件。
- 所有要求字段均已覆盖。
- 内容贴合 video-api-debugger 当前技术栈和目录结构。
- 验证命令通过或明确说明未执行原因。
- diff 可供 Claude Code 后续只读审查。

## 完成后汇报格式：

Codex 完成后必须汇报：

1. 改了哪些文件。
2. 每个文件具体写了什么。
3. 跑了哪些验证命令。
4. 验证是否通过。
5. 是否存在越界或风险。
6. 遗留问题与下一步建议。
7. 统一 diff。

## 是否需要 CC 先分析：

填写：是 / 否。

建议：

- 低风险文档任务：通常否。
- 涉及高风险区域、跨模块逻辑或不确定需求：是。

## 是否需要 CC 后审查：

填写：是 / 否。

建议：

- 文档规则、工程边界、权限、点数、数据库、Provider、上传等任务：建议是。
- 若需要后审查，应把 Codex 输出的统一 diff 交给 Claude Code 只读审查。
