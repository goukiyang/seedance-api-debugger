1. 同一工作台上半部只保一个配置区，使用“融合设定／身形比例／扩展维度”三组内页签。组内像用户原图直接点选；身形页签内四行35项一起可见，用户不必逐张展开。切组不丢选择，用轻量当前设定摘要保上下文。页签减少全页长堆，保主生成入口在配置下方，不移回组合台中间；原广场外壳与侧栏继续。
2. 角色定位常显；锁头紧贴类别名，固定状态常显；移出保持选择、规则和再次加入入口。高级必出/排除、自定义标签在“规则”内，只有实际修改摘要按情境出现，不重新加基础/已加入/12可用等常态噪声。
3. 固定要求用开关和紧凑输入，清楚表明下次生成生效；生成方式、数量、生成按钮继续在配置下方。同页结果出现后可连续调整/再生成，原撤销保留。固定要求有改动且已选结果时，才出现应用到这些行的操作。
4. 结果区以名称、可读提示词、保留状态为主；批量复选框和保留图钉各司其职。每条常显展开全文/复制当前语言/调整入口；元数据、规则检查与三阶段结构扩写按需查看。无伪分数或重复字段表。
5. 语言只保一套全局中文/英文/双语选择，预览/单条复制/批量复制/纯提示词TXT同步，按钮写明语言；原“译文”入口保留。缺英文就地给补齐/模型入口，中文仍可用，不自动补齐或偷偷换模型。图片里的“复制中文组合”沿同一语言，不另造重复英文数据。
6. “增加卡片”继续LLM对话、预览、确认加入；建议以侧边抽屉承载长对话，保输入和草稿，避免插入多轮聊天把生成/结果推走。关闭/重开不自动提交或重发。型号与更新继续复用页面设置现有范例、目录、可用性和账号记忆。
7. 顶部“保存配方／我的配方”服务配置复用；拟新增“保存方案／已存方案”服务本人结果保存。二者保存对象不同，成功反馈与失败保留分别对应真实回执，不自动共享，也不改旧配方定义。TXT/CSV及复制、原位清除二次确认、撤销、手动单组加入和所有已有能力仍保可达。

### 阶段与实施边界

推荐以**本模块专用、增量增加的五类记录**落在现有 Prisma/SQLite：`CharacterFusionCategory`、`CharacterFusionTerm`、`CharacterFusionWorkspace`、`CharacterFusionResult`、`CharacterFusionOperation`（拟新增模型名）。分别对归属/更新时间、类别/启用、文档/结果顺序、文档/操作编号建立实际查询需要的索引；不新增存储服务。设置与描述可用有版本的 JSON，结果按条存并分页，不把整个目录、聊天和所有结果放进一个全局可变 JSON，也不每次输入重写全部历史。

保留内置目录，扩展记录按稳定 ID 合并读取；停用内置项是可恢复覆盖，不删除源码原项。旧中文值只在读取边界按明确旧映射适配，别名保留；未知词条/新格式不能被旧解析器静默过滤再保存。新写入使用有格式版本的引用，旧配方继续可读；仅用户明确保存/另存时产生新格式，不批量迁移历史。程序回退不回退数据，旧客户端不能编辑其无法完整识别的新格式，须保草稿并提示刷新。

普通新增类别使用数据驱动的“描述属性”处理；母体、跨界、身形数量/比例等沿固定引擎处理器注册。新增类型先校验必需语义字段与中英描述，预览实际生成影响；不允许词条携带脚本、SQL 或任意可执行规则。只增加词条/普通类别不应反复修改引擎。

**多选不能混义：**固定组合＝全部用于每条新结果；候选池＝从池内按规则随机；“本批必出”沿原整批覆盖；未加入、明确无、未指定、随机分开存储。空候选池不自动变成全库，真正无匹配或范围冲突须保留现场并说明原因。硬约束由引擎校验，软偏好影响排序和建议；“温柔的反派”等反差不能被 LLM 自作主张排除。

### 4. CATALOG01：内容入库与筛选闭环

1. **可找到入口：**原页面低频管理区增加“词库管理”，与现有工作台/我的配方同一工具内切换；返回仍是原创作现场。卡片上的手选与搜索继续可用，不强制先进入管理页。
2. **内容来源：**手动填写、现有自定义卡片显式收录、LLM 建议和 CSV/JSON 导入均先进入同一草稿。中文名称、英文名称/生成描述、中英对应、类别语义与选择规则一起预览；已有有效译文不反复重译，缺译不冒充双语完整。
3. **筛选与去重：**先按权限、类别、关键词/别名/标签缩小范围，再让 LLM 在有 ID 的有限候选中推荐；结果可分页继续查。精确重复在相同归属/类别内提示复用；相似名称不能直接合并不同含义。不先全量灌入上下文，也不将检索的一页说成全库完整筛选。
4. **确认入库：**沿原“草稿 → 确认加入”交互，普通可逆操作不逐工具弹确认。导入先校验并预览新增/重复/错误项；一次提交的有限批次全成或全不成，较大文件分批且逐批回执，失败只接续未完成批次。确认后才成为正式目录内容，不以聊天里说“记住了”冒充入库。
5. **真正接通：**提交后更新目录版本，失效本账号/适用共享范围的检索缓存；卡片、分组、LLM 查询与新生成读取相同版本。新增项可定位并加入当前卡片，新类别不会默认挤入所有人的工作台。
6. **维护与历史：**改名、补译、停用须检查版本；历史结果不变。旧配方引用停用词条仍可查看原文，恢复后需明确当前可生成范围；不能无提示删掉该项或用别的词顶替。已有历史快照可继续复制导出。

权限推荐：所有当前有权使用工具的活跃账号可读内置及现有授权共享目录；个人扩展仅本人可改，正式共享目录由现有管理员管理，不新增角色。普通用户能提交个人草稿/建议，不因聊天自动公开；共享发布必须明确作用范围。此为待实施采纳的权限默认，不能借本规划实际扩大权限。聊天/创作现场默认本人私有，入库只提交明确选择的词条字段。

### 5. AGENT01：对话控制与执行闭环

主路径为：**说想法 → 保存为本人创作摘要 → 检索 → 设置候选/组合 → 原引擎抽卡 → 保留或局部调整 → 反馈进入本次摘要 → 保存/恢复/导出。** 例如“保留第3、7条，其余更像深海学者，巨掌巨脚都要，别带武器”，应形成保留指定结果、固定巨掌巨脚、设置候选与排除武器、替换其余结果的同一明确操作组；不能只是回复一段建议文字。

统一操作面向手动按钮和 LLM，不能由两者各写一套状态修改：

| 操作种类 | 允许能力与约束 |
|---|---|
| 读取 | 查询类别、分页检索词条、读取本人文档/结果；返回真实 ID、范围、版本与下一页信息，不返回他人私有内容。 |
| 设置 | 局部修改设置、固定组合、候选池、排除/必出和加入/移出；只修改指定字段，不接受 LLM 整包覆盖所有设置。 |
| 生成/调整 | 调原 `generateBatch/changeRow/reviseRow` 等共享引擎；指定目标结果和修改轴，保留已锁定项及其它已满意内容。 |
| 整理/使用 | 指定保留结果、更新本次摘要、保存配方、查询原操作、撤销。导出仍沿原按钮及冻结内容；AI 可帮助选中，不靠自动下载宣称已交付。 |
| 内容维护 | 生成词条草稿、建议类别和中英描述；正式入库走上一节的同一校验与本人/共享权限。 |

请求带文档 ID、客户端操作编号、基础版本、实际目标 ID 和必要目录版本，身份从服务端会话获取。可把一次指令中的相关设置与抽卡组成一个操作组，校验后短事务提交；LLM 推理、检索和外部网络等待不占 SQLite 写事务。LLM 输出只作为有类型的操作提案，参数、权限和业务条件在入口校验一次，不能执行任意脚本或直接写库。

**正常并发与失败接续：**

- LLM 回复期间手动编辑：对比它实际涉及的字段/结果版本；无冲突的其它编辑保留，同字段冲突保留双方草稿并就近给出差异，不能用旧全量状态覆盖新选择。另一页签同理，不为一项修改锁全页。
- 写入成功才显示“已应用”。回复超时或断线先用原操作编号查询；同编号同载荷可安全重试，不换新编号再抽一批。查询暂时无记录不证明旧请求永远不会到达；防重复靠事务内唯一编号。此约定只适用于新模块操作，不改旧媒体未知请求规则。
- 取消推理可中止未提交的提案；已提交操作须查回执，不能假称已取消。需要撤销时按真实前后版本撤销最后可逆操作；后续手动修改冲突则保留当前成果，不整份倒回。
- 失败保留输入、旧结果与可用设置；模型不可用/上下文超限给出真实原因，继续手动操作，不静默换型号或循环重试。分组操作未提交就不产生半批结果；多次已提交操作各自有回执，不能一条失败说成前面全部撤销。
- 工具循环有界：首版每个用户回合最多 6 次工具往返，并受既有模型请求时限及上下文上限约束；达到上限停止继续调用，保留已提交回执和未执行提案。用户可明确继续，不在后台无限消耗；读取可以批量，相关写入合为明确操作组，不靠循环反复抽到“满意”。
- 从摘要与有限最近对话构造上下文，每次附当前现场；不把无限聊天历史塞进现有 40 条/24000 字符通路。摘要可编辑且保留原始明确要求，不能用模型总结覆盖用户刚改的值。单条反馈默认影响当前目标/本次创作，长期个人偏好须显式保存，不自动学成全局禁令。

“导出选中”和“重抽时保留”分开为 `selectedIds` / `retainedIds`；旧现场初始化时沿原选中保留含义兼容，原导出/复制操作继续可用。用户说“保留”时有明确状态及取消入口，不把只想复制的勾选永久当锁定。单条调整从该条快照出发，不回写下批全局设置。

保存恢复：创作时进入一个本人工作文档，原设置/想法改动按合并后的局部操作持久保存；同步失败保留浏览器草稿并提供重试，只有服务器确认才表示已保存。原浏览器现场首次“继续/保存”时显式承接，不批量上传历史；服务端空白不能覆盖已有草稿。明确文档链接优先，否则继续本人上次文档；返回时恢复摘要、设置、保留项和结果位置，不重播生成动作。切号/退出中止旧账号前端接续，迟到回复不能写入新账号。新工作文档默认本人私有；维护入口支持改名、查找、继续及可恢复归档，永久删除不纳入本次默认自动化。
