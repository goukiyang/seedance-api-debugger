# 2026-08-13 资产管理页面切换与点击卡顿优化

## 1. 目标复述

用户要解决的是：`https://sd2.youdooart.com/assets` 资产管理页面在页面切换、点击筛选、打开选择模式、拖拽框选和加载资产时明显卡顿。目标不是只加 loading，而是把平均等待和交互阻塞压到最短，让用户能马上点、马上看到结果，并且不影响生成、上传、下载、超分、分享、项目/用户权限这些既有功能。

做到完成的标准：

- 页面切换不再因为全局导航重复请求用户和点数信息而变慢。
- 资产列表重复打开时优先显示已缓存内容，同时后台刷新新数据。
- 框选时不再每次鼠标移动都同步读取全部卡片位置。
- 项目/用户/图集等辅助数据按需加载，并使用轻量接口。
- 已上传素材默认隐藏、选择框只在选择模式出现、超分标签和下载入口等既有体验不能回退。
- 本地验证通过后，按服务器链路部署到 `sd2.youdooart.com`，并用公网页面/API 复核。

## 2. 具体执行任务

- [x] 统一登录态和点数读取：新增全局 `AppSessionContext`，让 `AppShell` 和页面共享 `/api/auth/me`、`/api/me/credits` 结果，避免路由切换重复请求。
- [x] 给资产页保留本地 IndexedDB 缓存，并补充缓存 TTL 和写入后按用户失效，避免过期缓存长期污染列表。
- [x] 将项目列表和管理员用户列表改成 `lite=true` 轻量接口，只返回资产页需要的字段。
- [x] 让项目列表、管理员用户列表、参考图集继续按需加载，不在资产页首屏无条件请求。
- [x] 优化框选：拖拽开始时一次性记录卡片位置，移动过程走 `requestAnimationFrame`，避免每次移动都读 DOM。
- [x] 为资产列表增加开发环境性能探针，记录网格重绘和长任务，方便后续继续定位。
- [x] 加 CSS 渲染隔离：资产日期分组使用 `content-visibility`，卡片媒体区使用 `contain`，导航 hover 不做位移。
- [x] 扩展 `scripts/assets-library-performance-smoke.ts`，把上述性能约束写成可复测检查。
- [x] 跑本地验证：性能烟测、TypeScript、Lint、生产构建、diff 检查。
