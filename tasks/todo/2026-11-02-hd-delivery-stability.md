# 高清稳定性与大图读取优化

状态：v0.130.0 已部署，广泛功能待用户手动验收；完整高清 1 秒目标继续。

已交付：

- 空闲调度减少历史清单扫描和无变化写入，保留低频补漏与原任务恢复。
- 新高清采用独立版本的 AVIF A 配方；原件、旧成品、文字及透明保护保留。
- 已知归属直接使用，历史恢复优先使用已有地址索引；异形旧地址保留兼容查找。
- 首击与查看器复用同一读取会话及保存的高清/原图选择。
- 修复延迟保存覆盖新选择、刷新后历史标记碰撞导致大图不能关闭。
- 首击描述请求从中止后重发改为一次。

工程证据：单响应读取 53 组客户端、19 组后端及 Works 合成契约通过；最终整合版完整 Next/types/lint 与原生发布门通过。发布保留一致数据库备份、相容程序恢复版、原有价格与权限。高清差量没有新生成、DDL 或业务数据恢复；整合版其他工作新增的表由原发布者保护。

有限实页证据：高清选择关闭刷新后保留；带旧 active 历史状态刷新后，新打开可正常关闭。

历史对照（v0.129.7）：同一约 2.12 MB、2880×2880 高清在 Ego 的冷开呈现约 2.03 秒；缓存重开无下载，内容约 0.54 秒就绪，实际呈现约 2.00 秒。Ego 的帧调度约 1 秒，独立 Chrome 呈现对照尚未完成。不能据此宣称 1 秒达标或全站稳定提速。

后续：继续收缩高清传输与解码耗时，补齐正常前台呈现对照。保持新鲜授权、版本绑定、拒绝清缓存、原图选择及旧版相容；格式对照仅为私有实验，未改变生产策略，不新增云资源或批量重压历史。

完整运行与浏览器证据保留在正式项目根的对应工单与私有材料目录，不随源码公开。

单响应接续已随 v0.130.0 保护部署，最终整合源的完整构建通过。旧 server JSON 相容保持；模板与作品详情的完整高清均由一次响应交付，缓存重开在实际呈现前无需重新下载图片。最新有限样本：模板冷开 2271.9ms、缓存 2006.8ms；另一张作品详情冷开 2229.2ms、缓存 2036.5ms。Ego 本会话仍约一秒帧间隔，独立 Chrome 对照未完成，不宣称整体提速或一秒达标。归属调度器与已验证修复字节一致，正常路径不再逐份扫描全部资产；异形旧地址兼容路径仍保留。
