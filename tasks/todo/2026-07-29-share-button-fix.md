# 分享按钮失效修复

## 1. 目标复述

用户反馈线上分享功能按键没有用。本轮要修复 `sd2.youdoodesign.com` 当前分享入口点击无效的问题，让用户点击分享后能打开可操作面板或完成对应共享动作，并部署到线上验证。

## 2. 可执行任务

- [x] 锁定当前线上代码目录、分支、Git 状态和分享入口所在页面。
- [x] 追踪分享按钮从前端点击到接口调用、状态更新、错误提示的完整链路，确认断点。
- [x] 只修导致按钮无效的根因；不重做共享模型、不改数据库结构、不扩大权限规则。
- [x] 补必要的失败提示或禁用态，避免用户点击后没有反馈。
- [x] 本地运行类型检查、lint/build 或等价验证。
- [x] 部署到 `sd2.youdoodesign.com`，验证公网页面/API 已加载新版本。
- [x] 形成聚焦 commit、push，并登记版本记录。

## 3. 验收/审查

- [x] 目标入口：图集列表/图集详情/单图卡片中的分享按钮点击后必须有可见反馈，能打开共享面板或提示明确错误。
- [x] 功能行为：共享面板保存时必须调用现有共享 API，成功后页面状态刷新；失败时显示明确原因。
- [x] 数据安全：不新增表、不复制图集、不修改真实生产数据做测试；只验证接口结构和 UI 行为。
- [x] 运行证据：`npm run lint`、`npm run build` 通过；公网 `/collections` 或相关静态资源能证明新构建加载。
- [x] 独立只读审查：已由独立子 agent 只读审查，不改文件、不提交、不部署。结论：通过；缺口是未写入生产共享记录做 E2E、未在已登录浏览器做点击录屏级验收。

## 4. 审查对齐检查

- [x] 审查必须围绕“分享按钮点击无效是否修好”，不能跑偏到重新设计共享权限体系。
- [x] 如果发现问题其实来自未登录、权限不足、数据库缺迁移或线上旧构建，必须把结论说清楚，不能用 UI 假反馈掩盖。
- [x] 如果需要真实写入共享记录才能最终验收，先停下说明风险，避免未经确认污染生产数据。
