# WallVerse 第一组「世界迁移」声音闭环

## 1. 目标复述

第一组 24 秒预演片已经有可用画面，但当前完全无声。这次先查清声音在哪一层消失，再保留已有画面补出一版与断电、世界离屏、迁移、新电视承接和结尾卖点同步的声音设计。完成标准是成片存在真实 AAC 音轨、全片可解码、关键声音与画面时间点对应，并通过独立只读审核。

## 2. 具体任务

- [x] 只读核对两条成功任务和此前音频失败任务的 `generate_audio`、状态、错误与点数退回记录。
- [x] 用 `ffprobe` 核对两条源片和 24 秒合成片的实际流，确认声音是否在模型源片、下载或合成阶段丢失。
- [x] 保留现有 24 秒画面，制作不含对白的预演声音设计：空间底噪、断电、世界唤醒、浮岛升起、跨屏迁移、进入新电视和结尾落点。
- [x] 输出带声预演版；视频保持 H.264/yuv420p，音频使用 AAC/48kHz/双声道，不覆盖无声源文件。
- [x] 验证 `ffprobe`、全片音视频解码、音轨响度和关键时间点同步；抽查开头、断电、迁移、落位、结尾五个节点。
- [x] 若声音设计无法清楚支撑画面，停止交付并只调整音频，不重新消耗点数生成画面。本轮未重生成画面，视频码流 MD5 与无声版一致。

## 3. 独立只读验收

- [x] 发送给固定审核线程 `审核001 - sd2 固定只读审查`。
- [x] 审核 agent 不修改文件、不提交 Git、不补实现，只读取两条源片、无声合成片、带声成片、任务参数、账务记录和媒体检查结果。
- [x] 通过标准：根因结论有数据库和媒体流双重证据；带声版包含可解码 AAC 音轨；声音没有爆音、明显断裂或盖过后续可能加入的旁白空间；关键声画节点对齐；原无声版本保持不变。
- [x] 审核输出必须包含：通过/不通过、证据、阻塞问题、非阻塞风险和下一步。固定审核记录结论为通过、无阻塞。

## 4. 目标对齐复核

- [x] 检查本轮是否真正解决“为什么没声音”和“如何继续推进展示版”两个问题，而不是只解释参数或只给建议。
- [x] 检查是否错误重生成了已通过的画面、重复扣点，或把模型自动音频失败误说成后期合成故障。
- [x] 检查最终汇报是否区分：原任务配置、源片音轨、合成片音轨、补声结果、Git/部署状态和仍需制作的正式音乐/旁白。
