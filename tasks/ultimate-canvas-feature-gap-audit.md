## 结论

新无线画布现在更像“可交互的前端工具 Demo”，不是已经完整接入 sd2 后台体系的正式生成工具。

已完成的是：页面入口、登录保护、iframe 包装、画布首屏、节点创建、节点拖拽、连线、缩放、提示词弹窗、导演台本地 3D 操作、部分截图转节点。

没闭环的是：项目归属、画布保存、真实视频/图片生成、点数扣减、素材库、生成历史、下载结果、协作分享、通知、反馈、全屏路径的登录态一致性、移动端适配。

## 关键缺失清单

### P0 阻塞：不补就不能作为正式生成工具

| 缺口 | 当前现象 | 本质问题 | 建议闭环 |
|---|---|---|---|
| 真实生成接口未接入 | `generation-api.js` 默认 `endpoints: {}`，没有 endpoint 时走 `mockGenerate`，返回 provider=`mock` 和“接口已预留” | 点击生成不会创建 sd2 后台任务，不会轮询状态，不会产出视频或图片 | 给 iframe 注入真实配置，至少接 `/api/video/create`、`/api/video/status/:id`、`/api/assets/generate`；按节点类型映射文生视频、图生视频、首尾帧、文生图等请求 |
| 画布无保存/加载 | 项目名是 `contenteditable`，节点数据只在 `window.canvasEngine` 内存里 | 刷新即丢失；无法回到项目继续编辑 | 新建 `canvas_documents` 或新 workspace canvas API，保存节点、连线、视图、项目、视频卡、资产引用 |
| 没有项目/视频卡归属 | 外层只检查登录，iframe 内没有项目选择和 project_id/video_card_id | 无法进入现有项目、视频卡、资产、成本链路 | 进入画布前必须绑定项目和可选视频卡；请求生成时带 project_id/video_card_id；结果回写项目资产和任务 |
| 点数和成本没有闭环 | 页面显示“预览版，不扣点”，节点里 `⚡ 6/40/135` 是静态文案 | 外部看起来像扣点，但实际不扣也不估价，和 sd2 计费体系脱节 | 接 `/api/tasks/estimate` 或统一价格表；生成前冻结/校验点数；成功扣减、失败退款，写入点数流水 |
| 生成结果没有轮询和下载 | `applyGenerationResult` 只把返回内容装饰到当前节点，没有状态轮询、视频预览、下载、截图 | 生成任务无法从 running 到 succeeded，用户无法验收结果 | 节点生成后进入 pending/running/succeeded/failed 状态；展示缩略图、视频预览、下载按钮、失败重试 |
| 素材库没接后台 | 素材面板固定显示“暂无素材” | 不能选择已有参考图、上传图也不会进入站内素材库 | 接 `/api/assets/list`、`/api/assets/upload`、参考图集；支持拖素材到画布、节点引用、分类筛选 |
| 生成历史没接后台 | 历史面板固定显示“暂无生成记录” | 和 sd2 任务历史、项目产出、最近任务完全断开 | 接任务列表和项目产出 API；支持从历史拖入画布、复用任务、下载结果 |

### P1 主要缺口：影响可用性和业务可信度

| 缺口 | 当前现象 | 本质问题 | 建议闭环 |
|---|---|---|---|
| 外层 iframe 和站内体系隔离 | iframe 只加载 `/tools/ultimate-canvas/index.html`，没有用户、项目、CSRF、配置注入 | 工具不知道当前用户是谁，也不知道可用模型和权限 | 外层用 `postMessage` 或同源 bootstrap JSON 注入 user/project/settings；iframe 请求统一走站内 API |
| “全屏打开”路径需要确认登录策略 | 外层全屏链接指向静态 `index.html` | 可能绕开外层产品壳层；如果 middleware 变更，可能出现未登录也能访问工具主体 | 全屏也走受保护 route，例如 `/tools/ultimate-canvas/fullscreen`，不要直接暴露静态 HTML |
| Header 协作/分享/通知/头像没有业务动作 | `btn-collab`、`btn-share`、`btn-notification`、`user-avatar` 只有 DOM，没有绑定功能 | 用户会以为可协作、可分享、可看通知，但点击无反馈 | 未实现前隐藏或置灰；实现后接项目成员、分享链接、通知中心、用户菜单 |
| 帮助和反馈按钮没有闭环 | `tool-help`、`tool-feedback` 无 panel 绑定，也没事件处理 | 用户遇到问题没有入口；反馈无法进入现有反馈后台 | 接现有反馈组件或 `/api/feedback`；帮助接简短快捷键和使用规则 |
| “从生成历史选择”未处理 | 菜单里有 `data-action="from-history"`，代码只处理 `upload` | 点击不会有结果 | 接历史选择弹层；支持选择视频、图片、参考图并创建节点 |
| 模型/规格/参数只是静态文案 | 例如 Seedance 2.0 VIP、16:9、720P、5s、无线 Navo Pro | 用户无法切换模型、比例、时长、分辨率、音频 | 接后台模型配置和价格配置；参数变化要影响估价和真实请求 |
| 节点引用没有转换成真实参考资源 | `sourceNodes` 只收集前端节点 data | 首尾帧、图生视频无法拿到 provider 可访问 URL | 对图片/视频节点建立 asset_id/reference_image_id；生成前把引用转换成公开 URL 或内部资产 ID |
| 错误态不足 | `submitNodeGeneration` 没有 catch UI，只 finally 取消 loading | 后端失败时用户看不到可操作错误 | 节点展示失败原因、重试、复制错误、联系反馈；接口错误写 operation log |

### P2 次要缺口：影响规模化使用

| 缺口 | 当前现象 | 本质问题 | 建议闭环 |
|---|---|---|---|
| 移动端适配很弱 | `styles.css` 只有一处 `@media (max-width: 820px)`，主要针对提示词弹窗 | 画布节点大量固定宽度，例如 350/622/640px，手机上容易溢出或难操作 | 先定义最低支持设备；若支持移动端，要做触控拖拽、面板折叠、节点缩放和横屏引导 |
| 本地 3D 资源较重 | `public/tools/ultimate-canvas` 约 17MB，导演台资源约 16MB | 首屏可能加载慢，尤其移动端和弱网 | 3D 资源懒加载；进入导演台时再加载 GLB；增加加载进度和失败提示 |
| 无撤销/重做 | 画布引擎没有 undo/redo 栈 | 创作工具误操作成本高 | 增加历史栈，覆盖节点增删、连线、文本、位置、参数 |
| 框选只记录单 selectedNodeId | 框选时会给多个节点加 selected class，但只保存一个 selectedNodeId | 多选后不能统一拖拽、删除、复制 | 补 multiSelection 数据结构和批量操作 |
| 删除确认使用 `confirm` | Logo 返回首页使用浏览器原生 confirm | 和项目危险操作规范不一致，视觉也粗糙 | 换成站内确认弹窗，明确“未保存会丢失” |
| 无快捷键提示 | 有缩放和 fitView 快捷键，但页面没有可见说明 | 用户发现不了 | 帮助面板列出快捷键和基础操作 |
| 可访问性不足 | 很多 icon-only 按钮靠 title，部分交互是 div/span | 键盘和读屏体验弱 | 给按钮补 aria-label，非按钮交互改 button，补 focus 样式和 tab 顺序 |

## 推荐优先级

1. P0：先接真实生成链路  
   目标：画布里点“生成”必须能创建 sd2 任务、轮询状态、展示预览和下载结果。

2. P0：再接保存/项目链路  
   目标：画布属于某个项目或视频卡，刷新不丢，生成资产进入该项目。

3. P0：接点数和成本  
   目标：前端估价、生成前校验点数、成功扣点、失败退款、后台流水可查。

4. P0：接素材和历史  
   目标：已有素材能拖入画布，生成结果自动入库，历史可复用。

5. P1：把占位按钮处理干净  
   目标：没做的先隐藏或置灰；做了的要有真实反馈，避免误导用户。

6. P1：全屏与 iframe 配置统一  
   目标：全屏也走登录保护和配置注入，不让静态工具脱离后台体系。

7. P2：补撤销/重做、多选、移动端、a11y  
   目标：从“能试”提升到“能长期用”。

- [ ] 成功任务能预览、下载、入项目资产。
